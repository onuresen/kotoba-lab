# Radical Alchemy visual assets

`laboratory-backdrop.webp` is an original, text-free illustration generated
with OpenAI's built-in image generation tool on 2026-08-15, then reviewed,
cleaned of an unwanted corner emblem, resized to 1599 × 900, and optimized to
WebP for the static site. It supplies atmosphere only; no study fact, kanji,
component, label, or control is encoded in the image.

Final prompt direction: a wide Japanese alchemist's workbench with aged washi,
indigo shadows, vermilion and antique-brass accents, warm lantern light, quiet
central space, restrained magical atmosphere, and no text, symbols, people,
logos, or watermarks.

`alchemy-icons.svg` is project-native source artwork. Its flask, crucible, book,
seal, transmutation-circle, and spark symbols use `currentColor` so contrast and
state remain controlled by the application palette.
